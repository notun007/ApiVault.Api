# Regenerated backend

This package is the ApiVault backend without a generated API-reference/documentation subsystem.

Removed:

- Documentation UI package and middleware.
- Framework API-description package and endpoint mappings.
- Generated catalog-document controller and service.
- Generated document URL from version responses.
- Related configuration and launch-browser behavior.

Preserved:

- JWT authentication and role authorization.
- Oracle 19c and Entity Framework Core 10 integration.
- API assets, releases, lifecycle, endpoints, environments, secrets, projects, exact version links, test execution/history, SSRF protection, redaction, limits, and audit logs.
